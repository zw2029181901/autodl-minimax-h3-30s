# MiniMax-H3-30s

独立的30秒有声视频应用。原有MiniMax-H3-ComfyUI的15秒版本、镜像、仓库与发布记录保留；本项目使用新仓库、新工作流和新的保存镜像。

默认30秒、24FPS、736×416，采用124帧渲染窗与22帧上下文连续生成720帧，20步原生采样。不是放慢、复制帧，也不宣称模型原生单次生成30秒。长片可能出现人物或声音漂移。

已完成真实30秒GPU生成及前端验收：720帧、24FPS、736×416、32kHz双声道，七段全部成功，生成与解码检查约13分钟（不含首次模型下载）。已抽查首尾及全部接缝相邻画面；未完成完整人工听看，不承诺任意提示词的画质。平台真实关机再开机后，6006服务已自动恢复；尚未额外创建全新实例验证镜像恢复。镜像与社区提交状态见 `DEPLOYMENT.json`。

## 运行与存储

建议使用32GB或更高显存。已测试平台vGPU-32GB，系统识别为RTX4080SUPER、32760MiB；其他GPU尚未完成本项目的实际验证。ComfyUI与节点源码使用固定提交，具体见 `sources.json`。

已保存独立镜像`MiniMax-H3-30s-v1`，平台大小0.56GB。先检查平台公共模型挂载。没有挂载时，四个默认权重需要下载到免费50GB数据盘，合计约42.47GB；权重不写入系统镜像。不自动扩容付费存储。

使用镜像创建实例后，打开自定义服务6006。首次启动显示模型准备进度，完成后自动进入工作流。填写`global_prompt`，点击运行；更换参数或内容时使用新的`chain_id`。相同任务名和参数可续跑已完成片段。结果位于`/root/autodl-tmp/minimax-h3-30s/output`，释放实例前需下载保留。

工作流与模型许可分别保留，不把上游模型声明为自研原创。模型采用MiniMax H3 Community License，节点采用GPL-3.0-or-later，ComfyUI采用GPL-3.0；完整通知随构建保存。
